# 变更汇总：v2.0.200 → v2.0.350（2026-11-20 ~ 11-21）

> 生成方式：`git log --oneline v2.0.200..HEAD` 按主题归并。
> 每条都能在 `git log` 或对应 GitHub Release 里找到原始提交。

## 任务可见性与反馈

- **任务列表加「节点」列**（allNode 显示「全部节点」），projection 补 `node`/`allNode`（2.0.345）
- **当前模块耗时分级**：≥20 分钟标黄、≥60 分钟显示「疑似停滞」（阈值按实测从 10/30 调高，2.0.346→347）
- **ETA「约剩 X」**：按已用时间÷完成比例线性外推；`progress≥5%` 且已跑 5 分钟才算，超 24 小时不显示（2.0.348）
- **ETA 改用 `startedAt`**：每次启动/恢复写入，暂停时长不再计入；无该字段的存量任务前面加 `≈`（2.0.349→350）
- **失败任务显示失败原因**：巡检判定失败时写 `failReason`，界面直接显示（2.0.299）
- **工具失败与进度并存**：`cmdFail>0` 时不再吞掉模块/目标/时长（2.0.293）
- **批量开始返回逐个结果**：「已开始 3 个，2 个未开始：原因」（2.0.322）
- **删除回确切条数**：单删/批量删都提示「已删除 N 个」（2.0.323）
- **筛选条件持久化**：节点/状态筛选存 localStorage，顶部提示「已恢复上次筛选」+ 一键清除（2.0.321）

## 加载 / 刷新 / 等待

- **多标签页轮询选主**：localStorage 选主 + 12s 过期 + 主标签关闭后自动接管；覆盖任务/节点/首页/系统状态/备份/ICP/MCP 七页（2.0.334→339）
- **MCP 审计页调用流**：8 秒自动刷新，后台暂停，显示「更新于」，可关闭（2.0.333）
- **节点页自动刷新**：15 秒 + 「更新于」提示（2.0.318）
- 所有自动刷新统一走 `useVisibleInterval`：可见时刷新、后台暂停、回前台补一次

## 调度与队列

- **四道派发闸门**：队列(5/节点)、容器内存(≥90%)、同前缀(3/节点)、限流(10/分钟)
- **拒绝计数与记录**：`dispatch-stats`（进程内）+ `dispatch_recent`（落库 30 天 TTL），节点页展示「前缀占满 3」并可展开看最近 5 条（2.0.311→317）
- **入队去重**：同一任务在同一节点只排一条；命中重复时顺手清理历史副本（2.0.286→300）
- **`queue-drain.py`**：把某前缀的待开始任务从队列撤下并暂停（默认预演，可逆）

## 节点稳定性与可观测性

- **容器内存上报**：节点读 cgroup v2/v1，心跳带 `containerMem`（宿主 `memNum` 看不出 cgroup 压力）
- **自动降压**：连续 3 次 ≥90% 把任务并发降到 1，连续 3 次 ≤70% 恢复（池调整在独立协程，避免卡死心跳）
- **内存趋势**：`node_mem_samples`（4 分钟一条、7 天 TTL）+ `node/mem-peaks`（1h 峰/均值/连续高压分钟）+ 界面「1h 峰」「高压 N 分钟」
- **Go 软内存上限**：启动读 `/sys/fs/cgroup/memory.max`，`debug.SetMemoryLimit(0.7×)`；任务结束 `debug.FreeOSMemory()`
  - 实测：三台 74-99% → 51/88/56%，节点不再反复被判离线
- **部署后 90 秒稳定性断言**：逐节点查心跳/状态，掉线即部署失败退出

## 发布与部署链路

- **gzip + 4MB 分片上传**：服务端 96MB→30MB（8 片 60s，原 24 片 184s）；节点 164MB→50MB（13 片 ~108s）
- **断点韧性**：分片单片重试、远端 sha256 校验、失败回滚、构建 nohup 分离
- 单连接传大文件会被中途 reset（~8MB），这是改分片的直接原因

## 事故与修复（都在 RUNBOOK 有复盘）

| 事故 | 根因 | 修复 |
|---|---|---|
| 三台节点连环崩溃 | 心跳无条件写空 `modulesConfig` → 池初始化为 0 → `ants.NewPool(0)` panic | 条件写入 + 池兜底 + 序列化失败不写 |
| 容器 Dead | overlay 快照 NotFound（宿主高负载） | `docker rm -f` + compose 重建 |
| 节点反复离线 | Go 不读 cgroup，RSS 顶到容器上限 | `SetMemoryLimit(0.7×)` |
| 部署后掉线无人发现 | 部署脚本只报"注册成功" | 90 秒稳定性断言 |
| 稳定性断言只查一台 | `printf "%s"` 把空格串当一行 | 改 `for h in $NODES` |
